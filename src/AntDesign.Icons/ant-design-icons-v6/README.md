# Ant Design Icons SVG source

These SVG files are sourced from `@ant-design/icons-svg` 4.6.0, the icon data used by the Ant Design v6 source checkout.

The package contains both `inline-svg` and `inline-namespaced-svg` copies. This library uses only the 848 files in `inline-svg/{filled,outlined,twotone}`; the namespaced copies are not separate icons and are intentionally excluded.
